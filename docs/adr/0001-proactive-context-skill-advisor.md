# Adopt proactive Context Skill Advisor with user-controlled proactivity

SkillForge will add a proactive Context Skill Advisor that surfaces Evidence-Backed Suggestions by default, with `balanced` as the install-time Proactivity Level. The advisor uses Session Context, Project Context, and Personal Context by default, but follows Targeted Content Access rather than full indexing. It runs through Advisor Checkpoints and Scheduled Background Advising, writes suggestions to an Advisory Queue, uses Advisor State for feedback, and requires Confirmed Skill Use before invoking or applying any suggested skill.

This trades a broader default context surface for more useful skill recommendations, while constraining that surface with read-narrow behavior, confidence thresholds, explicit evidence, user-controlled proactivity, project overrides, and suppression feedback.
